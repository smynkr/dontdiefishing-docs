The mobile app is organized around four bottom tabs:

| Tab | What it does |
| --- | --- |
| **Dashboard** | Loads saved-site conditions and shows a next-trip panel. Refresh to request the saved-site list and conditions again. |
| **Sites** | Browse launch sites by region, save them, and open site details. The Map button is present only when the phase-one map feature is enabled in that build. |
| **Trips** | Create or review trip plans and record a GPS track. |
| **Settings** | Manage account details, vessel profiles, alert preferences, and device-notification permission. |

## Dashboard and site details

The Dashboard can show a saved site's current score/status, wind, waves,
temperature, visibility, precipitation, and contributing signals. When no sites
are saved, it directs you to Sites. A failed refresh clears the dashboard's
cached verdict rather than presenting an old score as current.

Site detail can show the current vessel-specific verdict, freshness, signal
breakdown, tide and daylight context, community reports, and available fishing
regulation references. A missing value or score is not a safe result. Verify
current official conditions and local rules before acting.

An iOS Dashboard widget implementation exists in source, but the source release
record still lists native-device validation as open. Do not rely on the widget
or infer that it is available in a public store build.

## Sites and the feature-gated map

Sites browses curated launch sites with region pills. Open a site or use its
bookmark control to save or unsave it. Saving changes only after the request
succeeds; on failure, the app shows an error and retains the prior state.

When the phase-one Map feature is enabled, the map:

- plots the union of curated and saved sites;
- uses available batch scores for marker color and a neutral marker when a
  score is unavailable;
- opens site detail when a marker is selected; and
- uses a plain, network-free background without nautical tile sources.

The map still fetches the catalog, saved-site state, coordinates, and scores.
It does not use phone GPS to center the view, and it is not an offline catalog,
marine chart, or navigation instrument. A load or renderer failure provides an
error/retry or return state.

## Trips, tracks, and Settings

The Trips tab supports trip plans and foreground GPS track recording. Track
recording requires foreground location permission; background access is
optional, so a session can continue in the foreground if background permission
is declined. See [GPS tracks](/dontdiefishing/tracks) for recording, recovery,
and web replay.

Settings can manage account display details and vessel profiles (Power, Sail,
Kayak, or Paddle), choose a default vessel, and select Cautious, Moderate, or
Experienced scoring. Alert sensitivity and device push permission are separate:
changing an account preference does not enable push on a device. The mobile
source does not provide an in-app Pro purchase flow; subscription upgrades and
billing management are on the web.

Native push registration and delivery code is present, but the release record
says device credentials and real-device delivery receipts remain unverified.
Do not promise that mobile alerts will arrive. See [Alerts](/dontdiefishing/alerts).
