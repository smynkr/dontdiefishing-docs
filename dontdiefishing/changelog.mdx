What's new in DontDieFishing documentation.

## 2026-08-14 — Full regulation coverage

- Saltwater fishing regulations now available for every launch-site state
  (23 states, up from Massachusetts only) — size limits, bag limits, and
  seasons sourced from official state agency pages
- Each regulation card links to its official source and shows a last-checked
  date; a daily automated recheck flags stale rules for re-curation
- Custom sites now require a state selection so user-created spots resolve
  regulations too

## 2026-08-10 — Documentation rebuild

- Docs moved to a new documentation platform with clean URLs, related-guide
  wayfinding, and fail-closed content gates.
- All existing pages carried over: getting started, finding spots, safety &
  conditions, FAQ, and this changelog.

## 2026-07-31 — Initial documentation launch

- Getting started guide with spot browsing and safety-first workflow
- Finding spots: search, filters, spot detail, community reports
- Safety & conditions: data sources (USGS, NOAA, NWS), hazard categories,
  limitations
- FAQ covering spots, alerts, and saltwater fishing
