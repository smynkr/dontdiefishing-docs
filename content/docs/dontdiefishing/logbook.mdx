Use the web **Logbook** to record a fishing trip, catches, and optional trip
context. Historical conditions attached to an entry describe that saved trip;
they are not today's conditions or a current safety score.

## Record a trip

Choose a date (today or earlier) and add one or more catch lines:

| Field   | Entry                                                  |
| ------- | ------------------------------------------------------ |
| Species | Select a listed species or **Other**.                  |
| Count   | A non-negative whole number when a catch line is used. |
| Size    | Optional measurement in inches.                        |
| Weight  | Optional measurement in pounds.                        |

Use **+ Add species** for another line. Leave catch lines empty to record a
skunked trip. A line with a species but no count must be completed before it can
be saved.

Optional trip fields include notes (up to 2,000 characters), bait/lure (up to
120 characters), vessel, duration, gas consumed, engine hours, and passengers.
These are personal logbook data, not a gear recommendation or shared equipment
catalog.

## Entry sections and summaries

**Entry sections** controls which fields are shown on entries and forms:
catch details; weather and conditions attached from the trip; distance from a
linked track; duration; vessel; gas; engine hours; passengers; and photos (Pro).
Turning a section off hides it without clearing its saved value.

The logbook summarizes total fish and species, number of entries and drafts,
largest recorded size, leading launch site, and tide window when relevant
history is available. Catches by risk band, best tide phase, top species, and
historical insights are based on recorded entries. A catch without enough
snapshot data remains unknown rather than receiving a new score.

## Edit entries and filters

Use the species filter to show confirmed entries, a species, or drafts. Entries
are sorted newest first. Edit a confirmed entry to update catch lines or trip
fields; an entry with no catch lines can remain a skunked trip. The editor
validates species/count and numeric measurements before saving.

Mobile draft-catch and confirmation code is present in the repository, but no
public mobile store build has reached users. Do not assume that draft catches
are available in a released mobile app.

## Tracks and photos

A track-linked entry can link back to its GPS replay. Track duration can be
shown automatically until you explicitly edit it. See [GPS tracks](/dontdiefishing/tracks).

Photo galleries are a Pro feature. Enable **Photos** in Entry sections, then
add up to 10 images per entry (each 10 MB or smaller). If a photo or gallery
fails to load, the entry remains and the UI reports an error so you can retry.
