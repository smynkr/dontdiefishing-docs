Use the web app to configure the craft you plan to use, browse Launch Sites,
review available conditions, and keep a trip plan ready for another check before
you go.

<Callout type="warn">
  A planning score is not a guarantee of safety or permission to launch.
  Forecasts are uncertain, condition sources can be incomplete, and the app does
  not replace official warnings, local closures, or your own assessment.
</Callout>

## 1. Create an account

Choose **Sign up** to register with email and password. Google sign-in is
available; Apple sign-in is shown only when the web provider is configured as
available. Email confirmation may be required. Protected app pages require an
authenticated session.

## 2. Configure a vessel profile

Onboarding asks for a vessel type and scoring profile. Available vessel types
are **Power**, **Sail**, **Kayak**, and **Paddle**; profiles are **Cautious**,
**Moderate**, and **Experienced**. These choices set starting thresholds and
weights. Add or edit profiles in **Settings**, choose a default, and configure
custom thresholds or weights if needed.

If a conditions panel says a vessel profile is required, add one in Settings and
retry. A score is personalized only to the vessel shown with that result.

## 3. Choose and save a launch site

1. Open **Launch Sites** and choose a region.
2. Compare the curated sites in its map and site rail.
3. Open a site to review available details; select **SAVE** to add it to your
   account, or **PLAN TRIP** to start a plan.
4. Use **NAVIGATE** to open the destination in an external map service.

The web map is region-based and does not request browser geolocation. Change
regions to browse elsewhere. You can also use web-map **Pin** mode to add a
custom, owner-scoped launch site; it is saved to your account and is not a
public submission. See [Finding spots](/dontdiefishing/finding-spots).

## 4. Check current conditions

Open a site detail or Dashboard and review the selected vessel, status, score,
condition age, available-signal count, and evidence. A missing score, unavailable
source, or stale label means you should verify conditions directly; it is not a
favorable result. A **GO** score is not authorization to launch.

Tide and daylight/solunar information are contextual planning details, not a
substitute for current observations. Follow official NWS, NOAA, and other cited
authority links where shown.

## 5. Plan the trip

Open **Trips** and choose **Plan a Trip**. Select a launch site, vessel profile,
date, and optional departure time. Review the readiness preview and create the
plan. Reopen it as departure approaches to check the latest result, forecast
availability, and your selected vessel's limits.

A planned date does not guarantee a forecast will be available. Missing forecast
intervals remain unavailable rather than borrowing another day's score.

## 6. Verify before departure

Before leaving, check current official weather and marine warnings, relevant
closures and regulations, and conditions at the site. The regulation catalog is
a selected reference subset; read the cited authority's current rule and
emergency order. A float-plan link is informational, not a distress service or
confirmation that someone is monitoring the trip.

## Location and mobile release status

Browsing launch sites and maps does not require device location access. The
mobile Sites map also uses site/catalog data rather than GPS. When starting a
mobile GPS track, foreground permission is required; background permission is
optional, so foreground-only recording can continue if background access is
declined. If foreground permission is denied, recording cannot start. See
[GPS tracks](/dontdiefishing/tracks).

The source release record says there is no public App Store or Google Play build
yet. Mobile pages describe features present in repository code, not a verified
store release or physical-device availability. See [Mobile app](/dontdiefishing/mobile-app).
